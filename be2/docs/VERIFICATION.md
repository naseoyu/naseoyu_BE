# BE 2 검증 기록

2026-10-07 / Linux / Python 3.12 / SQLite 기준.

- 자동 테스트 **23개 통과**.
- 실제 별도 API 프로세스와 워커 프로세스에서 Preset 조회 → 시나리오 저장 → 분석 대기 → 모의 Agent 실행 → SSE → 리포트/JSON 다운로드 확인.
- DB Preset 저장과 반복 초기화 시 기존 데이터 보존.
- 시나리오 버전 충돌, 기존 스냅샷 보존, 동시 중복 요청의 단일 작업 생성.
- 모의 결과 표시 및 미계산 금액 null 처리.
- SSE 재생·재개·다른 분석의 커서 거절·최종 이벤트 확인.
- 취소·재시도, 중복 취소, 완료 작업의 잘못된 상태 전환 거절.
- 동시에 여러 워커가 획득할 때 단일 실행 소유권 확인.
- 임대 만료 회수, 이전 워커의 늦은 이벤트·완료 저장 차단.
- 실행 중 취소 후 결과 저장 차단, 워커 정상 종료 시 재대기.
- Agent 예외·잘못된 결과·금지된 이벤트·이벤트 한도 초과·타임아웃 처리.
- Agent revision 불일치, 시도 한도, 입력 스냅샷 변조 거절.
- 마이그레이션 반복 적용과 ORM 스키마 일치, PostgreSQL DDL 컴파일.
- 로컬 포트 충돌 시 다른 포트 선택, 잘못된 Agent 설정 확인.
- Wheel 빌드 및 패키지 내 마이그레이션 포함 확인.

Windows BAT의 네이티브 실행 및 실제 PostgreSQL 서버 연결은 검증하지 않았습니다. BE 1의 실제 Agent·LLM·비용 계산은 연결 대상이며 이 프로젝트의 검증 범위에 포함하지 않습니다. 모의 Agent는 테스트용으로만 제공됩니다.
